Push API Demo

Subscribe to the browser's push service and read push payloads with the Push API. The Push API needs a secure context (HTTPS or localhost), a registered service worker and a push service that sends the encrypted messages.

Subscription

The subscription hangs off registration.pushManager. A real push needs a VAPID key and a server, so subscribe() may report an error here.
